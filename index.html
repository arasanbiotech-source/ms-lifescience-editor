Preview & export

The editor creates article HTML for Blogger's post editor. It does not publish directly to your blog or upload media.

After exporting, copy the HTML and paste it into Blogger's post editor using its HTML view. Add labels and search description in Blogger separately.

How to add this editor to your blog
  1. Host this index.html file on a static hosting service such as GitHub Pages.
  2. In Blogger, create a page named Visual Editor.
  3. In the page's HTML view, paste an iframe pointing to your hosted editor URL.
  4. Publish the page and add it to your blog menu.

Blogger may remove or restrict scripts pasted directly into a page. Hosting the editor separately and embedding it is the more reliable approach.
